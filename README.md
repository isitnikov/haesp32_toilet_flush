# Змив унітаза через Home Assistant

Кнопка **«Змити»** в Home Assistant запускає сервопривід MG90S через ESPHome. Серво закріплене під кришкою бачка й коротким рухом піднімає ланцюжок зливного клапана. Після короткої паузи качалка повертається, ланцюжок слабшає, і клапан може закритися. Штатна ручка залишається доступною для ручного змиву. Датчик для запуску не потрібен.

## Що потрібно

| Деталь | Призначення |
| --- | --- |
| **D1 mini на ESP8266** | Контролер ESPHome з Wi-Fi. У прошивці вибрано плату `d1_mini`. |
| **MG90S**, качалка та гвинт для неї | Качалка тягне ланцюжок клапана. |
| Два гвинти для монтажних вушок MG90S | Кріплять сервопривід до друкованої скоби. У моделі отвори Ø2,2 мм із міжосьовою відстанню 27,5 мм. Звір розміри зі своїм серво. |
| Короткий відрізок ланцюжка або тяга з гачком | З'єднує качалку зі зливним клапаном так, щоб штатна ручка теж могла його підняти. |
| Блок живлення **5 В / 2 А** | Живить плату й серво паралельно. |
| Дроти, розгалуження для 5 В і GND, кабель USB для прошивання | З'єднують блок живлення, контролер і серво. За потреби додай трижильний подовжувач серво. |
| Друкована скоба та дві половини корпусу | Скоба тримає серво на бортику бачка. Корпус захищає плату від випадкового дотику й тримає проводку. |

## Як закріпити

1. **Піджени скобу під бачок.** Зніми кришку й заміряй бортик у найтовстішій точці на глибині, яку охопить скоба. У OpenSCAD зміни `rim_thickness` (у моделі 10 мм) і за потреби `rim_clearance` (0,8 мм). Перевір місце під кришкою для перемички `bridge_thickness` (2 мм) та розміри канавки під кабель (5 × 1,2 мм).
2. **Зроби примірку.** Установи `part = "fit_check"`, відрендери модель через **F6** і експортуй STL. Примір скобу поруч зі зливним механізмом, перевір посадку кришки та вільний шлях ланцюжка. Після примірки зміни `part` на `"bracket"` й експортуй повну деталь.
3. **Установи MG90S.** Заведи роз'єм через верхній отвір кишені, встав корпус серво з внутрішнього боку бачка валом до центра бачка й закрути два гвинти через монтажні вушка. Насунь скобу на бортик кишенею всередину. Вклади кабель у канавку поверх бортика й перевір, що кришка сідає на місце без перекосу та не затискає дріт. Серво має бути вище рівня води й поза прямими бризками. Корпус D1 mini і блок живлення розмісти зовні в сухому місці.
4. **Вистав качалку й приєднай тягу.** Спочатку запусти цикл без ланцюжка, щоб перевірити напрямок і кінцеві положення. У початковому положенні закріпи качалку так, щоб її робочий хід піднімав клапан. Після приєднання залиш трохи слабини в ланцюжку, щоб клапан сідав на місце, а штатна ручка вільно працювала навіть із вимкненим живленням.
5. **Перевір змив.** Почни з малого кута й збільшуй його, поки клапан надійно відкриватиметься. Перевір, що качалка й тяга не зачіпають поплавок, стінку або кришку, а серво не впирається в механічний упор.

## Підключення

| Звідки | Куди |
| --- | --- |
| `+5V` блока живлення | Пін `5V` D1 mini і червоний дріт MG90S |
| `GND` блока живлення | Пін `GND` D1 mini і коричневий дріт MG90S |
| `D5` (`GPIO14`) D1 mini | Помаранчевий сигнальний дріт MG90S |

Кольори типові для MG90S. Перед підключенням звір розводку свого екземпляра. Плата й серво мають спільну землю. Живлення серво підведи безпосередньо від блока живлення через розгалуження. Частота PWM у конфігурації 50 Гц.

## Прошивання та налаштування

1. Додай [toilet-flush.yaml](toilet-flush.yaml) в ESPHome. У `secrets.yaml` задай `wifi_ssid`, `wifi_password`, `toilet_flush_api_key` і `toilet_flush_ota_password`.
2. Для першої прошивки через USB від'єднай зовнішні 5 В і серво. Після прошивання від'єднай USB, підключи все за таблицею та додай пристрій **Toilet Flush** в інтеграції ESPHome у Home Assistant.
3. Налаштуй хід серво в Home Assistant. Кнопка **«Змити»** запускає один цикл. Її також можна викликати з автоматизації Home Assistant.

| Параметр | Початкове значення |
| --- | --- |
| Початкова позиція | 90° |
| Напрямок повороту | До більшого кута |
| Кут повороту | 15° |
| Час підняття | 0,6 с |
| Час утримання | 0,5 с |
| Час повернення | 0,6 с |

Значення зберігаються після перезапуску. Задані кути номінальні, тому орієнтуйся на фактичний хід качалки. Цільовий кут дорівнює початковій позиції плюс або мінус кут повороту за вибраним напрямком. Якщо ціль виходить за межі 0–180°, прошивка пропускає цикл і пише попередження в журнал. Повторні натискання під час змиву ігноруються. Після повернення в початкове положення керування PWM вимикається.
